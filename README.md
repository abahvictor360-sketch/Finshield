# Finshield

A responsive landing page for **Finshield**, a fintech brand. It uses plain HTML, CSS and JavaScript with no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

- `index.html` holds the page markup: hero, about stats, features, benefits, partners, testimonials and footer.
- `styles.css` holds the styles and responsive breakpoints (1000px and 760px).
- `script.js` handles the mobile nav, feature accordion, benefit and testimonial sliders, count-up stats and scroll reveals.
- `assets/logo.svg` is the favicon and logo mark.
