## Upwork / Fiverr portfolio project

**Title:** Finshield: responsive fintech website with scroll animations

**Role:** Front-end developer

**Skills:** HTML, CSS, JavaScript, Responsive Design, Web Animation, Landing Page, Vercel

**Description:**

A complete 25-page website for a fintech brand, built from a design mockup and deployed live on Vercel.

What I delivered:
- A pixel-accurate homepage matching the design, plus 24 more pages: products and pricing, features, sign-up and log-in, company, resources, help center and legal pages
- A fully responsive layout for phones, tablets and desktops
- Scroll animations: word-by-word headings, staggered reveals, parallax depth, a sticky menu and a scroll progress bar
- Interactive features: a pricing switch, a cashback calculator, a searchable FAQ, category filters, a download pop-up and form validation
- Fast, lightweight code with no frameworks, and animation that respects each visitor's accessibility settings
- Hosting on Vercel with automatic updates
